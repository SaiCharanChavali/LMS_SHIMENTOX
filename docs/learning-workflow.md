# ShimentoX Learning

A responsive LMS portal with an HTML/CSS/JavaScript frontend and a Python/SQLite backend, using the supplied ShimentoX logo. Includes candidate accounts, a combined dashboard, course search, video walkthroughs, exercises, timed examinations, and printable certificates.

Run `npm start` from the project root, then open http://localhost:5173. Signed-out candidates see login; authenticated candidates see the dashboard. Opening the HTML directly does not run the API.

Admins create candidate accounts with assigned emails and temporary passwords. Public registration is disabled. Candidates must choose a different personal password on first sign-in, before accessing any course. The same portal shows role-appropriate pages: candidates have Dashboard, My courses, My profile, and Achievements; admins have account/course management and audit pages. SQLite stores roles, hashed passwords, sessions, and individual learning records. Logging out invalidates the session. My profile provides later password changes and personal record exports.

Python Programming has three sequential sets: Python foundations, Strings and collections, and Logic and reusable code. Each contains two original 48-second silent video walkthroughs with English captions/transcripts, two multiple-choice practice exercises, and one four-question exam. Videos must be watched to completion; seeking ahead does not record completion. Exercises require both answers correct and allow unlimited retries. The next set unlocks after the previous set is complete.

Each set exam has a 10-minute deadline, a 75% pass mark, and at most three attempts per course run. An attempt is consumed on start. Failed, timed-out, and terminated attempts all count. SQLite transactions enforce attempt limits; the server grades answers and checks deadlines and prerequisites. Tab switching, window blur, navigation, reload, or closing the page ends an active attempt. Interrupted attempts are reconciled on reload. The exam view hides navigation while active. Browser events cannot block other apps/tabs or provide secure proctoring. Video watch reports also remain client observations.

After all six videos, six exercises, and three exams are complete, a certificate is generated with the candidate name, logo, course, and completion date. Open My achievements and use Print / Save PDF. A new course run resets all requirements and exam attempts, while retaining earned certificate snapshots. There is no limit on fresh course runs. Previous text-only lesson completion does not satisfy the new assessment requirements.

Run `npm start` at project root to serve both frontend and backend. Opening HTML directly or using a static server does not run authentication. Run `npm test` for frontend API-contract checks and real HTTP/SQLite integration tests. These cover candidate isolation, authentication, persistence, prerequisites, scoring, attempt limits, interruption, deadlines, repeat runs, and certificate eligibility. The frontend checks use a simulated DOM; full browser playback and print layout still require manual verification. The original local video assets are included; `frontend/tools/generate_videos.py` regenerates them using Pillow, NumPy, OpenCV, and the Windows Segoe UI/Consolas fonts. Python Programming Senior runs practice code in an isolated browser runner. The backend does not execute learner code.
